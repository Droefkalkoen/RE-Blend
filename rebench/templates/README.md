# RE Bench templates

`rebench new` copies one of these folders into a new device project and fills in the device's
name, manufacturer and identifiers.

**Licence of the template files.** The files in this folder are released under CC0 1.0
(public domain dedication): a device started from them is yours to license however you like,
commercially included, with no obligation from RE-Blend's GPL. This applies only to the
template files and what `rebench new` writes from them, not to the rest of this repository.

The templates contain no Reason Studios material. To build the device you need the Rack
Extension SDK, which you get from Reason Studios under their own licence.
